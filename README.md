# Bank Application Automation - Cucumber BDD Framework

This project automates a banking web application using Selenium WebDriver, Java and Cucumber BDD framework.

## Technologies Used
- Java
- Selenium WebDriver
- Cucumber BDD
- Maven
- TestNG

## Test Scenarios Automated
- User Login
- New Customer Creation
- Edit Customer Details
- New Account Creation
- Logout

## Project Structure
src/test/java → Step Definitions and Test Runner  
src/test/resources → Feature files  
pom.xml → Maven dependencies
